# 📊 2026-pop : 연령별 인구 구조 시각화

행정안전부에서 제공하는 **연령별 인구현황(월간)** 데이터를 기반으로,
지역별 인구 구조를 한눈에 확인하고 인구 구조가 비슷한 지역을 찾아주는
Streamlit 웹앱입니다.

Streamlit Cloud에 배포되어 있으며, 그래프는 [Plotly](https://plotly.com/python/)를 사용해 인터랙티브하게 렌더링됩니다.

## ✨ 주요 기능

- **지역 검색/선택**: 시/도, 시/군/구, 읍/면/동 단위까지 포함된 전체 지역 목록에서
  선택하거나 이름을 직접 입력해 검색할 수 있습니다.
- **연령별 인구 구조 꺾은선 그래프**: 선택한 지역의 0세 ~ 100세 이상 인구를
  계/남/여로 구분해 시각화합니다.
- **인구 구조 유사 지역 Top 5**: 선택한 지역과 연령별 인구 **구성비**가
  가장 비슷한 지역 5곳을 코사인 유사도 기준으로 찾아 표와 그래프로 보여줍니다.
  (절대 인구수가 아닌 연령별 비율로 정규화하여, 지역 규모 차이에 영향받지 않도록 계산)
- **CSV 자동 인식**: 코드와 같은 폴더에 있는 CSV 파일을 자동으로 찾아 불러오며,
  사이드바에서 다른 CSV로 교체 업로드도 가능합니다.
- **기준월 자동 감지**: 컬럼명 패턴을 분석해 데이터 기준월을 자동으로 인식하므로,
  매달 새로운 CSV로 교체해도 코드 수정 없이 동작합니다.

## 🗂️ 데이터

- **출처**: 행정안전부 [연령별 인구현황](https://jumin.mois.go.kr) (월간)
- **파일 인코딩**: CP949 (한글 CSV 표준 인코딩)
- **형식**: 행정구역별로 0세 ~ 100세 이상 연령별 인구수를 계/남/여로 구분해 제공

## 📁 폴더 구조

```
2026-pop/
├── main.py                                    # Streamlit 앱 코드
├── requirements.txt                           # 의존 패키지 목록
├── 202606_202606_연령별인구현황_월간.csv        # 인구 데이터 (원본 파일명 그대로)
└── README.md
```

## 🚀 로컬 실행 방법

```bash
git clone https://github.com/greatsong/2026-pop.git
cd 2026-pop
pip install -r requirements.txt
streamlit run main.py
```

## ☁️ Streamlit Cloud 배포

1. [share.streamlit.io](https://share.streamlit.io) 접속 후 GitHub 계정 연동
2. 이 저장소(`2026-pop`) 선택
3. **Main file path**를 `main.py`로 지정
4. Deploy 클릭

> CSV 파일은 코드와 같은 폴더에 있으면 자동으로 인식됩니다. 파일명이 다르거나
> 한글 파일명 인코딩(NFC/NFD) 문제로 인식이 안 될 경우, 폴더 내 첫 번째 `.csv` 파일을
> 자동으로 탐색하도록 구현되어 있어 별도 설정이 필요 없습니다.

## 📝 참고 사항

- 인구 구조 유사도는 지역별 총인구 대비 연령별 인구 **비율**을 기준으로 계산됩니다.
  따라서 인구 규모가 크게 다른 지역(예: 서울특별시 전체 vs 특정 읍/면/동)이라도
  "인구 구조의 모양"이 비슷하면 유사도가 높게 나올 수 있습니다.
- 시/도, 시/군/구, 읍/면/동이 하나의 지역 목록에 함께 포함되어 있어, 서로 다른
  행정 단위 간 비교가 이루어질 수 있습니다.
